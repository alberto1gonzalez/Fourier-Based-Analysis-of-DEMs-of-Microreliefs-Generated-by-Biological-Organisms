Herradura: Fourier-Based Analysis of Digital Elevation Models (DEMs) of Microreliefs Generated by Biological Organisms
Author: Alberto González Díez
________________________________________
Overview
This repository contains a MATLAB-based workflow for the spectral analysis of Digital Elevation Models (DEMs) using one-dimensional (FFT1D) and two-dimensional (FFT2D) Fourier transforms. The methodology was developed to identify characteristic spatial frequencies in topographic surfaces and to apply Butterworth low-pass and high-pass filters for geomorphological analysis.
The repository includes:
•	MATLAB scripts.
•	Auxiliary filtering functions.
•	A synthetic DEM representing a horseshoe-shaped footprint.
•	ArcMap project files.
•	Filtering results and examples.

Workflow
The methodology follows four sequential stages:
DEM
↓
PRIMERO_ANALISIS_DEM_MODoct26.m
↓
Sedundo_FOSIL_eXTRAER_LAS_FRECUENCIAS_DE_FILAS_DE_UN_DEM3MODoct26.m
↓
segundo_A_analisis_relieve_frecuencia_MODoct26.m
↓
TERCERO_FOSIL_FILTRADO_FFT2_MOD_CUARTA_oct26.m

Stage 1. DEM inspection
PRIMERO_ANALISIS_DEM_MODoct26.m
Functions:
•	Reads a GeoTIFF DEM.
•	Identifies the number of raster bands.
•	Computes descriptive statistics.
•	Displays each raster band.
•	Automatically selects the DEM band.
Generated variables:
MATLAB
DEM
DEMband
Z
R
________________________________________
Stage 2. Spectral analysis (FFT1D)
Sedundo_FOSIL_eXTRAER_LAS_FRECUENCIAS_DE_FILAS_DE_UN_DEM3MODoct26.m
Functions:
•	Converts the DEM into a one-dimensional signal.
•	Performs FFT analysis.
•	Computes: 
o	Relative frequency.
o	Spatial frequency (cycles/m).
o	Wavelength (m).
•	Generates spectral plots.
•	Exports results to Excel.
Outputs:
•	Frequency spectra
•	Dominant frequencies
•	Wavelengths
•	Excel tables
________________________________________
Stage 3. Relief-frequency analysis
segundo_A_analisis_relieve_frecuencia_MODoct26.m
Functions:
•	Explores the frequency distribution of the DEM.
•	Displays spectral information at different scales:
1.	Full spectrum
2.	Macrorelief
3.	Mesorelief
4.	Microrelief
•	Compares spectral behaviour with elevation distribution.
Outputs:
1.	Spectral plots
2.	Histograms
3.	Descriptive statistics
________________________________________
Stage 4. Butterworth FFT2 filtering
TERCERO_FOSIL_FILTRADO_FFT2_MOD_CUARTA_oct26.m
Functions:
•	Applies 2D Butterworth filters.
•	Generates:
1.	Low-pass DEM
2.	High-pass DEM
3.	Removed relief
•	Preserves geographic information from the source GeoTIFF.
•	Exports filtered models to ASCII raster format.
Outputs:
Plain Text
1.	*_LP_COFxx.txt
2.	*_HP_COFxx.txt
3.	*_REM*VIDO_COFxx.txt
Each exported file contains:
1.	ncols
2.	nrows*xllcorner
3.	yllcorner
4.	cellsize
5.	NODAT*_value
followed by the raster matrix.

Synthetic DEM
The repository includes a synthetic DEM representing a horseshoe-shaped footprint.
Characteristics:
1.	R*ster size: 784 × 784 cells
2.	Cell si*e: 0.001 m
3.	Surface size: 0.784 × 0*784 m
The model contains:
•	Horseshoe-shaped depression.
•	Correlated background roughness.
•	Internal microrelief.
•	Synthetic topography suitable for spectral testing.
The synthetic DEM provides a controlled environment for validating:
•	Frequency identification.
•	Cut-off frequency selection.
•	FFT2 filtering behaviour.
•	Geomorphological interpretation.
